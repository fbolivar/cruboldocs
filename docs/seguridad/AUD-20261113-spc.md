# Auditoría de seguridad — SPC / Gráficas de control (v1.6-3)

**Fecha:** 2026-11-13 · **Auditor:** rol adversarial (skill seguridad-saas) · **Alcance:** motor puro `src/lib/spc/compute.ts` (I-MR, Cp/Cpk, reglas de descontrol), query `listSpcSeries`, UI (`/app/spc`, `SpcBoard`/`ControlChart`/`CapabilityPanel`/`SignalList`), gate `canSeeSpc`, nav. **Sin migración ni cambios de base de datos.**

## Resumen ejecutivo (3 líneas)
SPC es **compute-only** (patrón Focos v1.5-4): no crea tablas, RPC, anon ni dependencias; calcula al vuelo sobre `inspection_results`/`inspections`/`inspection_plans`, leídos con la **RLS existente por `organization_id`** (roles SIG vía `canSeeSpc`/`can_see_inspections`). No hay escritura, ni dato personal (mediciones técnicas de producto). La estadística se degrada con seguridad (sin límites ni Cp/Cpk cuando faltan datos, sin inventar). **Veredicto: APTO.**

## Veredicto
**APTO** — sin hallazgos Críticos ni Altos.

## Hallazgos

| # | Severidad | Hallazgo | Evidencia | Estado |

| SP-01 | Info | Nueva ruta de lectura `/app/spc`. | Gate `canSeeSpc` (RISK_ROLES) en la página; los datos ya están bajo RLS de inspecciones; solo lectura, sin acciones ni RPC. | Aceptado |

| SP-03 | Info | Export CSV en el cliente. | `toCsv` (anti-fórmula, prefija `'` ante `=+-@`); la serie ya es visible para el usuario; sin datos de otra org. | Aceptado |

## Verificaciones realizadas
- **Aislamiento multi-tenant:** `listSpcSeries` filtra `inspection_results`/`inspections`/`inspection_plans` por `organization_id` con `scope()` y se apoya en las políticas RLS ya auditadas del módulo 057; no agrega SQL, RPC ni endpoints. No hay forma de leer series de otra organización (mismas políticas que inspecciones).
- **Sin superficie nueva de escritura:** no hay server actions con efectos; el único "action" es la descarga de CSV en el navegador. No se tocan `grants`, `anon`, ni se crea RPC `security definer`.
- **Robustez del cálculo:** motor puro con 13 pruebas unitarias (vitest): I-MR, Cp/Cpk (bilateral, un lado, no calculable), reglas (3σ, racha 8, tendencia 6) y umbrales del semáforo; división por σ̂ protegida (null si σ̂≤0); con <2 puntos no grafica.
- **Sin dato personal:** solo mediciones numéricas de características de producto; no se leen nombres de personas ni se exponen en el CSV.
- **Fuga / inyección:** `toCsv` neutraliza fórmulas; el gate evita render a roles sin acceso; no hay mensajes de error de base de datos (no hay RPC).
- **Advisors Supabase:** sin cambios (no hay objetos nuevos en la base).

## Conclusión
El módulo se puede desplegar. Es una capa de lectura y cálculo sobre datos ya protegidos por RLS, sin base de datos nueva ni superficie de escritura; la estadística se degrada con seguridad ante datos insuficientes. No hay Críticos ni Altos; los ítems Info/Bajo quedan aceptados o mitigados conforme a ADR-121/122/123.
